# The public website (www.mossfield.ie)

The farm's public site is generated by this app and uploaded to the Hosting
Ireland shared-hosting account as plain static files. The app does not serve
it; it only builds it.

## Build

```
php artisan site:build --clean
```

Writes `storage/app/site-build/` (gitignored): five pages, `404.html`,
`sitemap.xml`, `robots.txt`, `.htaccess` and `assets/`. `--out=DIR` builds
somewhere else. Output is deterministic, so two builds of the same inputs are
byte-identical.

## Preview

```
php -S 127.0.0.1:8081 -t storage/app/site-build
```

Then open http://127.0.0.1:8081/index.html. PHP's server ignores
`.htaccess`, so the old-URL redirects and the 404 page can only be checked on
the host.

## Where things live

| What | Where |
|---|---|
| Page templates | `resources/views/site/*.blade.php` (relative links only; no `@vite`, `route()`, `asset()`) |
| Stylesheet and images | `resources/site/assets/` (copied as-is into `assets/`) |
| Products shown | `resources/site/data/products.json` |
| Product photos | `resources/site/product-images/` (referenced by file name from `products.json`) |
| Stockists shown | `resources/site/data/stockists.json` (empty since 2026-10-26; the 2015 list is in `stockists-2015.json` for reference and is not published) |
| Contact details, awards, redirects, page list | `config/site.php` |
| Generator | `app/Site/SiteBuilder.php`, command `app/Console/Commands/BuildSite.php` |
| Data sources | `app/Site/Sources/Json*Source.php`, bound in `app/Providers/SiteServiceProvider.php` |
| Tests | `tests/Feature/SiteBuildTest.php`, `tests/Feature/SiteDataSourcesTest.php` |

### Editing stockists

Add an object to the `stockists` list:

```json
{"name": "Lilliput Stores", "county": "Dublin", "address": "5 Rosemount Terrace, Stoneybatter, Dublin 7",
 "phone": "01 672 9516", "products": ["milk", "yoghurt", "cheese"], "website": null, "show": true}
```

`name`, `county` and `products` (any of `milk`, `yoghurt`, `cheese`) are
required. `show: false` hides an entry without deleting it. A mistake stops
the build with the offending entry's index. The page groups by county and
sorts by name; with no entries it shows a "contact us" note instead.

### Editing products

Same shape in `products.json`: `slug` (lowercase, hyphens), `name`, `type`
(`milk`, `yoghurt` or `cheese`), `description` (a blank line starts a new
paragraph), optional `image` (file in `resources/site/product-images/`),
`sort`, `show`.

## Upload to Hosting Ireland

Manual for now. In cPanel's File Manager (or FileZilla), back up
`public_html`, then upload the contents of `storage/app/site-build/` into it,
including the dotfile `.htaccess` (turn on "show hidden files"). Then check:

- https://www.mossfield.ie renders over HTTPS.
- https://www.mossfield.ie/wheretobuy.html redirects to `/stockists.html`.
- https://www.mossfield.ie/nothing.html shows the 404 page.
