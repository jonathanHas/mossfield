# Cycle 16b — User guide, part 1: help pages and the order flow

Status: ACCEPTED
Revision: 1
Planner: Fable 5.1
Date: 2026-10-29

A guide the office and the floor can open from the sidebar, written from the
screens as they are after cycle 16, with pictures that are regenerated by a
script rather than pasted. This cycle builds the `/help` pages, the demo data
the pictures need, and the four pages of the order flow. Finance, stock and
admin pages are **part 2 (cycle 16c)**. Parked cycle 12 (delete guards) stays
cycle 17 — see `RESUME.md`.

## Goal

A signed-in user clicks **Help** in the sidebar and reads a short, task-shaped
guide to the screen they are on, with a picture of that screen. The pages are
Markdown files in `docs/guide/` (readable on GitHub and in Obsidian as well),
rendered by the app at `/help` and `/help/{page}`. The screenshots in
`docs/guide/images/` come from `docs/guide/screenshot.mjs`, so a cycle that
changes a screen can remake its picture with one command. Part 1 covers:
getting started, orders, the chilled run sheet, and picking on the phone.

## Constraints

- **Read-only rendering.** `/help` never writes anything. The page route
  reads only `docs/guide/<page>.md` and the image route only
  `docs/guide/images/<file>.png`; both are constrained by route regex
  (`[a-z0-9-]+` with an optional `.md`; `[a-z0-9-]+\.png`) **and** checked
  with `file_exists` on the resolved path, so no request can reach another
  file under `docs/` or anywhere else. No user input is interpolated into
  the Markdown.
- **No application rule changes.** Nothing in `app/` other than the new
  controller; no migrations; no changes to stock, money or status logic
  (`TESTING_AND_FIXES.md` → *Invariants worth keeping*).
- **The demo script is dev-only.** It starts with
  `if (! app()->environment('local')) { throw new RuntimeException('Dev only.'); }`
  and refuses unless `config('database.connections.mysql.database') === 'mossfield_cl'`.
  It never runs against production and never deletes anything.
- **Guide prose is checked against the code, not written from memory.**
  Each page's facts come from `CLAUDE.md` sections (named per page in step
  7) and from the views; where the two disagree, the view wins and you note
  it under *Notes for Planner*.
- **Route order.** `Route::fallback` stays the last line of `routes/web.php`.
- **Commit policy:** do not commit, push or deploy. Jon commits.

  Route::get('/help/images/{file}', [HelpController::class, 'image'])

  500 KB, say so.

  test can tell. Step 5's check is a human look at every PNG; the
  script-printed ids go in `implemented.md` beside the manifest.
